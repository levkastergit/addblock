# BlockAds

Собственный блокировщик рекламы для Google Chrome (Manifest V3).

## Установка

1. Скачайте `blockads-vX.Y.Z.zip` со страницы [Releases](https://github.com/levkastergit/addblock/releases) и распакуйте в отдельную папку
   (или склонируйте репозиторий).
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа вверху).
4. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку (ту, где лежит `manifest.json`).

После правки файлов нажмите кнопку ↻ на карточке расширения в `chrome://extensions`.

## Как работает

| Файл | Что делает |
|---|---|
| `rules/ads.json` | Блокирует запросы к рекламным сетям (Google Ads/DoubleClick, Яндекс РСЯ/Adfox, Criteo, Taboola и др.) через `declarativeNetRequest`. Сюда же попадают запросы видеорекламы (VAST) на сторонних сайтах. |
| `content/cosmetic.css` | Скрывает рекламные блоки на страницах, включая баннеры и рекламу в ленте YouTube. |
| `content/yt-main.js` | На YouTube удаляет из ответов плеера поля `adPlacements`, `adSlots`, `playerAds`, чтобы плеер не получал рекламу. |
| `content/yt-skip.js` | Запасной вариант: если реклама всё-таки началась — жмёт «Пропустить», либо выключает звук и перематывает ролик рекламы в конец. |
| `background.js` | Включает/выключает правила и скрипты, ведёт список сайтов-исключений. |
| `popup/` | Окно по клику на значок: общий выключатель и выключатель для текущего сайта. |

## Если реклама не блокируется

В окне расширения есть **Журнал запросов**: нажмите «Начать запись», запустите видео,
дождитесь рекламы и нажмите «Скопировать». В журнале видны все запросы вкладки
(включая плееры в iframe) — по нему можно найти, с какого домена приходит реклама.

Добавить домен в блокировку — допишите его в массив `requestDomains` в `rules/ads.json`.
Скрыть ещё какой-то элемент — добавьте CSS-селектор в `content/cosmetic.css`.
